# Données agrégées publiables — TERROVIA

Ce répertoire contient uniquement les synthèses nationales et régionales et les résumés agrégés des profils K-Means utilisés pour la démonstration hébergée.

Il n'inclut aucune observation individuelle, coordonnée précise d'exploitation, identifiant, affectation individuelle ou modèle sérialisé.

Les statistiques présentées décrivent les entités préparées et les équipements recensés. Les distances sont euclidiennes, en ligne droite, et les limites méthodologiques détaillées sont affichées dans le tableau de bord.

Les exports bruts et les couches détaillées ne sont pas diffusés ici.
